# 만두냥 도움말 (Discord 섯다 봇)

디스코드에서 섯다(Seotda) 게임을 즐기고, 출석체크로 보유금을 모을 수 있는 봇입니다.

**기능 한눈에 보기**
- 섯다 게임 (1:1 대결, AI 대전)
- 베팅/승부 진행 (체크/콜/다이/쿼터/하프/맥스)
- 족보 확인, 내 패 확인
- 출석체크 보상
- 내 정보(보유금/출석) 조회

## 시작하기
### 1) 기본 명령어
- `/섯다 기본금: <금액> 상대: @상대`
  - 상대 태그가 없으면 AI와 즉시 대전합니다.
  - 기본금 최소 1,000원
- `/출석체크`
  - 하루 1회 10,000원 지급
- `/내정보`
  - 보유금, 마지막 출석 날짜 확인
- `/족보`
  - 섯다 족보 확인

### 2) 섯다 게임 흐름
1. `/섯다`로 게임을 시작합니다.
2. 상대가 있으면 수락/거절 버튼이 표시됩니다.
3. 게임이 시작되면 차례대로 베팅을 진행합니다.
4. 서로 체크하거나 베팅이 종료되면 패 공개 후 승부가 납니다.

### 3) 베팅 버튼 설명
- `체크`: 베팅 없이 넘기기
- `콜`: 상대가 걸어둔 금액만큼 맞추기
- `다이`: 포기하고 판돈을 상대에게 양보
- `쿼터`: 판돈의 25%만큼 추가 베팅
- `하프`: 판돈의 50%만큼 추가 베팅
- `맥스`: 올인 (가능한 최대 금액만큼 베팅)

### 4) 패 확인 & 족보
- `패 확인` 버튼으로 내 패를 확인할 수 있습니다.
- `/족보` 또는 게임 중 `족보` 버튼으로 족보를 확인할 수 있습니다.

## 게임 규칙 요약
- 광땡: 38 > 13 > 18
- 땡: 장땡(10) > 9땡 > ... > 1땡
- 특수패: 알리, 독사, 구삥, 장삥, 장사, 세륙
- 끗/망통

## 참고
- 게임 상태는 메모리에 저장됩니다. (서버 재시작 시 진행 중 게임은 초기화)
- 출석체크 날짜는 KST 기준으로 계산됩니다.
